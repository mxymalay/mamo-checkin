# Windows installation

## English

Windows 10/11 x64 and Google Chrome are required. Download the [Chrome extension](https://github.com/mxymalay/mamo-checkin/releases/latest/download/mamo-checkin-extension.zip) from the latest GitHub Release, or install **Mamo Check-in** from the Chrome Web Store.

1. Extract the extension ZIP into a permanent folder.
2. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted extension folder whose root contains `manifest.json`.
3. Open the extension and follow the guide. Windows uses the built-in browser OCR locally; no separate OCR package is required.
4. Enter your school identity, sign in to Attendance, detect courses, choose Gmail or Moodle sources, and save.

Images and records remain on this computer. Low-confidence results stay available for review.

## 中文

# 马莫签到助手 Windows 安装指南

支持 **Windows 10/11 x64 和 Chrome**。请从[最新 GitHub Release](https://github.com/mxymalay/mamo-checkin/releases/latest)下载 Chrome 扩展包，或直接从 Chrome 网上应用店安装 **Mamo Check-in**。

1. 解压扩展包，并将文件夹放在固定位置。
2. 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择根目录直接包含 `manifest.json` 的扩展文件夹。
3. 打开扩展并按引导继续。Windows 使用本机浏览器内置 OCR，无需下载或安装 OCR 配套包。
4. 填写学校身份，登录 Attendance，检测课程，选择邮件/Moodle 来源并保存。

原图和记录保存在本机。置信度较低的结果会保留给用户核对。
