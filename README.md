# 马莫签到助手 · Mamo Check-in

Mac 版 0.7.6 · [GitHub 仓库](https://github.com/mxymalay/mamo-checkin)

使用 macOS 原生文字识别（Apple Vision），从 Gmail 和 Monash Moodle 读取文字与图片签到码，保存原图和记录，自动提交最近 7 天内、网站仍开放且五项信息完全匹配的课程场次。

新安装时姓名、邮箱、课程和来源网址均为空，自动运行关闭。升级保留使用者此前保存的设置。当前版本仅支持 Mac，不依赖浏览器内 WASM 图片识别，也不需要 AI 账号。

## 安装或升级

1. 解压 `马莫签到助手-Mac.zip`，把文件夹放在固定位置。
2. 双击 `安装Mac识别服务.command`。看到“Mac 原生识别服务已安装，自检通过”后即可关闭窗口。本机识别组件会复制到用户资料库中；不需要管理员密码。需要 macOS 12 或更新版本及可运行的 Python 3；安装命令使用 `/usr/bin/python3`，如系统提示安装开发者命令行工具，请先完成安装。
3. 打开 Chrome 的 `chrome://extensions`，打开开发者模式，加载包内的 `extension` 文件夹。升级时请把新版 `extension` 全部文件覆盖原先加载的文件夹，再点“重新加载”；不要卸载已有扩展，以保留设置和记录。如 Chrome 要求启用本机通信权限，请启用。
4. 关闭旧的马莫签到助手页面，从工具栏图标重新打开。页脚应显示 **0.7.6**。填写学校邮箱、学校系统中的姓名、年份及课程来源，开启自动运行并保存。
5. 在同一个 Chrome 配置文件登录学校 Gmail、Moodle 和[签到系统](https://attendance.monash.edu.my/student/Units.aspx)，点击“立即检查”。

如有个人配置文件，可在页面右上角点击“导入个人配置”一次导入并保存。个人文件与通用安装包分开保存，不包含在安装包中。

## 课程与检查范围

可添加最多 20 门同校课程。每门课填写 Gmail 发件人和唯一的主题关键词，或填写 Moodle 课程、Week 栏目、公告、页面的网址；也可同时使用两种来源。仅使用 Moodle 时发件人留空。

Gmail 查询最近 7 天的邮件，新消息按会话处理。Moodle 优先当前周、上周及相关签到页面，明确过旧的周范围跳过；每门课每轮最多检查 4 页，并保存后续进度。直接填写常用 Week 页面可以减少导航。无需为了测试而补交超过 7 天的旧课程。

每门课可填写每周节数，以及各节的星期、时间、活动类型和组别，时间按马来西亚时间（UTC+8）。配置旁的问号支持鼠标悬停或键盘聚焦查看说明。未填写课表时，首次从签到网站读取最近 7 天的场次（包括已签到场次），去重后保存为固定周课表，后续检查直接复用。信息不全或组别冲突时不自动保存，提示核对；网站无法读取时，不自动提交无课表课程。

填写课表后，先核对网站已有签到，再为最近 7 天内已开始且缺少签到码的场次查找来源。配置 Gmail 发件人时先查邮件；仍缺少场次且填写了 Moodle 网址时，再查课程页面。只配置 Moodle 时直接查课程页面。一门课所需场次均已有可靠签到码或网站显示已完成/过期，就停止该课程的后续来源检查。自动提交也限制在已配置的课表场次内。

图片读取支持附件正常跳转；直接下载失败时，尝试从仍包含该图片的同源邮件或课程页面读取原始图片。两种方式共享 20 秒上限，并显示具体的登录、格式、网络或超时问题。

完整文字表格直接读取；图片由本机识别，重复图片复用结果。页面显示正在处理的来源、步骤、耗时、计数和近期明细。原图与记录直接写入本机目录，无需逐个等待 Chrome 下载归档。正常速度取决于图片和网站响应；网络慢、登录过期仍会影响整轮耗时。

## 自动提交与保存

课程代码、日期、活动类型、组别和时间全部匹配、识别证据可靠、课程开始未超过 7 天且网站仍允许录入，才会提交。年份不可靠、多个候选码、信息不全或识别不确定时，保留为“需要核对”。提交前先保存检查点，提交后重新读取网站确认成功；结果不明时停止自动重试。

原图、识别缓存和记录保存在 `文稿/签到助手归档/`。设置页面显示实际路径，并可导出 CSV。扩展本地存储继续保存设置、记录和提交检查点。不读取密码，不向第三方 AI 上传图片。

默认每 1 天检查一次，也可选择每 3、5、7 天；修改后点击保存生效。保存并开启自动运行后，可以关闭马莫签到助手页面，后台定时器仍会执行。

保持 Chrome 运行、网络连通并登录学校账号；电脑睡眠或 Chrome 关闭时不会检查，也不会主动唤醒电脑。同一个账号建议仅在一台电脑开启自动运行。

## 验证边界

Mac 原生识别已在本机测试四张真实签到表格，并校验五个签到码及其完整场次信息；测试样本不包含在安装包里。本机的单张识别样本耗时约 0.2–0.6 秒，这不是整轮网站检查耗时保证。安装器检查本机连接程序、消息协议及识别文件是否存在且可执行；实际图片识别另行测试。

浏览器工具无法操作已安装扩展页面，因此实际 Chrome 原生通信、学校登录及真实提交的完整流程仍需在重新加载扩展后验证。当前没有与已有签到码对应、可用于测试的开放待签到场次，未进行真实提交。

## 开发

`npm ci`、`npm test`、`npm run build`。Mac 构建需要 Xcode 命令行工具，生成 Apple Silicon / Intel 通用识别程序，输出 `build/mac/` 和 `build/马莫签到助手-Mac.zip`。`samples/` 不进入安装包；旧版浏览器识别模块保留作回归测试，不包含在 Mac 安装包中。

检查结束时，打开的助手页面显示结果弹窗，列出近期记录及状态。未取得数据或信息待确认时提示核对课程配置；检查完成与签到成功分别显示，失败不会显示为成功。

首次打开且尚未保存课程时，先询问是否检测课程，用户确认后才读取已登录签到页面的近 7 天课程，自动生成课程代码和可编辑的固定周课表草稿；然后为每门课选择邮件、Moodle 或两者，补齐身份与来源信息并保存。此发现步骤只读页面，不提交签到。未登录或无近期场次时显示提示，可登录后点“重新检测课程”。重新检测保留已有来源，将新课表填入编辑区，核对保存后生效；未检测到的旧课程不会自动删除。

填写格式错误、重复或不完整场次会弹窗提示；网站待签到场次与已存课表不符时也会提示核对。记录上方按课程切换，课程内按 Week 分组：有来源周次则使用来源标注，否则显示明确注明的自然周及日期范围。

公开仓库的测试使用虚构身份与示例数据。真实邮件图片、个人配置、历史开发报告和依赖私有图片的本机 OCR 测试不上传；`npm test` 在新克隆中运行公开回归测试。安装包可在 Mac 上运行 `npm ci`、`npm run build` 生成。

为兼容已有安装，扩展标识、本机通信标识及历史归档目录继续沿用原值；界面名称和新安装包统一为“马莫签到助手”。
